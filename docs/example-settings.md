# 脱敏后的配置结构示例

这是配置结构示例，不是适用于所有地区的参数。身份、账号、地址均已移除。

| 连接 | 示例 VLAN/优先级 | 用途 |
| --- | --- | --- |
| INTERNET 路由 WAN | 41 / 0 | 家庭互联网；原记录有拨号用户名与 MRU 1492，需确认 PPPoE 选中状态 |
| TR069 路由 WAN | 46 / 6 | 运营商远程管理，不是互联网拨号连接 |
| TR069 桥接 WAN | 46 / 6 | 管理业务示例，不要复制为家庭上网 WAN |

原笔记包含 IPv4/IPv6 已连接以及 /64 前缀的信息，但没有保留 IPv6 取址/PD 单选框状态，不能据此推断 DHCPv6-PD 已选。

配置灰色可能与局端下发或账号权限有关。LOID 认证、OMCI/OAM 下发和 PPPoE 拨号是不同环节，不能保证输入 LOID 后自动获得完整 WAN。

新 XG 的 bosa/ri 必须来自该 XG 自己；旧光猫身份记录不能代替新光猫校准。ONT ID 通常是局端运行时分配值，不作为固定克隆配置。
